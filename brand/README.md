# depower logo

**Idea:** a D split by one stepped line, the shape of an hourly price.

## Files

Everything is in [`final/`](final/) as SVG, with PNG exports.

| Use | File |
|---|---|
| Symbol | `depower-symbol.svg`, plus black, white and blue versions |
| Small sizes, under 32 px | `depower-symbol-small.svg`, which has a wider cut |
| Horizontal logo | `depower-horizontal.svg` |
| Stacked logo | `depower-stacked.svg` |
| Word only | `depower-wordmark.svg` |
| Web icons | `favicon.ico`, `favicon.svg`, `apple-touch-icon.png`, `icon-192.png`, `icon-512.png`, `maskable-512.png` |

CMYK values are calculated, not press-tested, and no Pantone colour has been chosen. Check both with a printer before print use.

## Rules

- **Clear space:** keep at least a quarter of the symbol's height empty on every side.
- **Minimum size:** 32 px for the regular symbol, and 16 px with the small version. Keep the horizontal logo at least 24 px tall.
- **Backgrounds:** use blue or black on light backgrounds, and white or bright blue on dark ones. On photos, use white over a dark, even area.
- **Don't:** stretch or rotate it, change the step, fill the cut, add shadows or gradients, or redraw the word.

## Type

The word is Outfit Medium, converted to outlines, so no font is needed to display it. Outfit is licensed under the SIL Open Font License.
